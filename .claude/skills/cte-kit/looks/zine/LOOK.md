# Look: Zine / Photocopy

Handmade, human, punk. For `/cte-demo` by default (tutorials, "Catch it yourself").

- **Ground:** `assets/textures/Paper003.jpg` (crumpled white), slow 1.00→1.04 push.
- **Type:** headlines Permanent Marker 90–110 px, −2° tilt (handwritten, never perfectly straight). Step text and
  captions Courier Prime 700 44–52 px. Big step numerals Permanent Marker 190 px in red `#d4231c`.
- **Paper parts:** torn mounts (`print_fx.py torn` on a #FAF9F5 rectangle, seed fixed), tape strips (rgba(236,226,196,.82),
  jagged `clip-path`, ±18–28°), black caption chip for the one rule to remember, photocopied PD reactions.
- **Real media:** the recording or screenshot stays in true colour inside a torn mount — never photocopy UI (it must
  stay readable). Only reactions/photos get the xerox treatment.
- **Marks:** red marker pen (10 px stroke, round caps) circles or underlines one thing per beat, drawn in 0.35–0.4 s.
- **Motion:** step cards pop (scale 1.15 → 1, rotate −4 → 0, 0.18 s `back.out(2)`); camera zooms per action; no other
  movement. SFX: click on real clicks, pop per step card, scratch per pen stroke, stamp on the verdict.
- **Slop flags:** fake handwriting fonts in more than 2 places, scribble doodles/stars/arrows as decoration, glitter,
  rainbow tape, "notebook paper" lines, sticky-note clip-art, AI-generated photos.
